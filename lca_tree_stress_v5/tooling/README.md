# lca_tree_stress_v5 Tooling

This directory holds the shared outer-suite harness that used to live at repo
root.

Key entrypoints:

- `build.sh`
- `run_case.sh`
- `gate.sh`
- `gate_boj3s.sh`
- `hunt.sh`
- `suite_presets/`
- `lca_tree_stress_v5_tooling_solver.cpp`

Use `../build.sh` and `../smoke.sh` when working on the standalone
`lca_tree_stress_v5` solver workspace itself.
