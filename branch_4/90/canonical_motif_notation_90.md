# Canonical Motif Notation 90

## purpose

This document makes canonical motif language first-class for the `canonical_motif_compression` operation.

The notation separates motif compression from coordinate contraction:

- coordinate contraction quotients support coordinates by an accepted coordinate-equivalence relation;
- canonical motif compression rewrites a canonical motif to a lower-rank canonical representative, possibly without changing support size.

It also separates motif compression from family-chain absorption:

- motif compression reduces canonical rank inside a witness;
- family-chain absorption closes or reduces a family-chain support-growth component using bounded family-chain language.
