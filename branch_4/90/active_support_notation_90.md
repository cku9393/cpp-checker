# Active Support Notation 90

## purpose

This memo fixes the object language for `project_to_active_support`.

Active support is the subset of a normal support witness actually used by its obstruction payload, counterexample certificate, frontier/shell/tail descriptors, canonical motif dependencies, and recognized family-chain source/lift fields. Inactive support is the complement inside the declared support set.

This differs from redundant support. A redundant coordinate is a single coordinate presented with a deletion predicate. Inactive support is a set-level projection target; when the active set is a strict subset, the operation removes all inactive coordinates at once.
