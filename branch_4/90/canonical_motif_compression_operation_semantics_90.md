# Canonical Motif Compression Operation Semantics 90

## operation

`canonical_motif_compression` rewrites an accepted compressible canonical motif to a lower-rank canonical representative and normalizes the resulting witness.

This is not coordinate contraction.  It does not identify support coordinates by equivalence classes.  It is also not family-chain absorption, because it does not close a bounded family-chain component by theorem applicability.
