# Equivalent Support Coordinate Notation 90

## purpose

This memo fixes the notation used by `contract_equivalent_support_coordinates`.

Coordinate equivalence is not coordinate redundancy. A redundant coordinate can be removed because no required payload or certificate field uses it. Equivalent coordinates may both be active, but the current contract treats them as replaceable by one quotient coordinate only when payload, canonical, and status roles are congruent under the chosen equivalence relation.
