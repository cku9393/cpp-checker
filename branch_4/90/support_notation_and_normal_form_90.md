# Support Notation And Normal Form 90

## support definition

Support is the finite set of symbols participating in a witness antecedent/conclusion schema after canonical relabeling. Runtime analogue: the canonical structured local schema row and its `num` field.

## support8

`support8` means the normalized witness has support size at most `8`. Inside this scope, the selected limited theorem applies.

## normal form

A support witness normal form records:

- support size
- canonical schema row/fingerprint
- shell index
- tail descriptor
- frontier status
- family-chain component
- escape class

The normal form is proof-ready for routing, but full mathematical equivalence for arbitrary non-runtime witnesses remains a separate support/canonicalization obligation.
