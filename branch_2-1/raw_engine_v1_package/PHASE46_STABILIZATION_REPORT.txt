Design
- Operator decisions are explicit: approve, skip, defer, reject, close, retry_now.
- Decision apply updates ledger status and closure status without silently mutating current env budget state.
- Reproposal handoff default is handoff_only; integrated approval is not the default path.
- Ledger compaction retains active/failed/retry/approval actions and archives closed old entries.

Root cause / mitigation
- A direct full evidence-bundle run against the iCloud-backed authoritative artifacts root stalled while indexing/zipping the large artifact tree.
- The resolved path was to keep authoritative manifests as the source of truth, but build the bundle with a small local /tmp artifact index root and publish only the selected phase46 manifests, reports, and bundle outputs back into the authoritative tree.
- This is consistent with the staged/sparse verification lane: avoid long recursive work directly on the iCloud-backed tree.
